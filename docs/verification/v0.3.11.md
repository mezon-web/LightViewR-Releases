# LightViewR v0.3.11 の配布確認

PDFのページ番号の左右にある前後ページボタンの記号を大きくして、見やすくしました。

前後のページ移動、先頭と最終ページ、明暗テーマを確認しました。配布ZIPを展開して起動、設定・履歴・読書位置の保存を確認しています。公開後にZIPとチェックサムを取得し、確認済みの配布物と一致することも確かめました。

- 配布ファイル: `LightViewR-v0.3.11.zip`
- ZIPのSHA-256: `ed75408bc0f2c8da39f7c1a253e5a7bf12bd0e0a299dd1e5519b3fd1af27154e`
- Windows x64と .NET 10 Desktop Runtime x64 が必要です。Markdown・HTMLには WebView2 Runtime も必要です。ランタイムはZIPに含まれていません。
- Windows 10実機では未確認です。旧版の設定を引き継ぐには、終了後に `UserData` を新しいEXEの隣へコピーしてください。
