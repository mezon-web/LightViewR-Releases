# LightViewR v0.3.12 の配布確認

長いMarkdownでスクロールバーのつまみとマウスポインターがずれていく問題を修正しました。本文ブロックの高さを最初に計算し、従来の余白と見た目を保ちます。

配布EXEに含まれるDLLと同梱の表示ファイルで、長文、表・コード、画像、上下ドラッグ、拡大と幅変更、検索移動、読書位置復元を確認しました。測定したつまみのずれは最大1pxでした。隔離環境でブラウザへ入力を送る自動検証であり、物理マウスによる確認ではありません。

ZIPを展開したEXEでMarkdown・HTML・PDFの起動と通常終了を確認し、Markdownの履歴・読書位置の保存も確認しました。GPUを使わない低負荷設定で実施しています。

同じ修正の小規模な比較では、約299KiBのMarkdownの初期描画は中央値78.35→89.32ms、短い文書は58.26→58.66msでした（各3回）。環境や文書によって異なり、アプリ全体の起動時間ではありません。

- 配布ファイル: `LightViewR-v0.3.12.zip`（8,520,342 bytes、229ファイル）
- ZIPのSHA-256: `c175edaf01b319902914f17a023c80685d680fdae0a1dbbe8527317de3bd6ddb`
- 個人設定、.NET Runtime、WebView2 Runtimeは含みません。
- Windows x64と .NET 10 Desktop Runtime x64 が必要です。Markdown・HTMLには WebView2 Runtime も必要です。
- 後から読み込まれる画像や数式による高さの変化は別の要因として残ります。Windows 10実機、複数モニターのDPI、利用者の元文書は未確認です。

旧版の設定を引き継ぐには、アプリ終了後に `UserData` を新しいEXEの隣へコピーしてください。
