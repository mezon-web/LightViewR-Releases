# LightViewR v0.3.10 の配布確認

検索結果の塗りを薄くし、検索語のクリアと本文のクリック位置からの検索移動に対応しました。

![検索語のクリア](../../assets/search-0.3.10.png)

配布ZIPを展開し、PDF・Markdown・テキスト・表・HTMLの起動、設定・履歴・読書位置の保存を確認しました。公開後にZIPとチェックサムを取得し、内容が確認済みの配布物と一致することも確認しています。

- 配布ファイル: `LightViewR-v0.3.10.zip`
- ZIPのSHA-256: `0d6485f0c7aab64bc3acebab92ce86c01892bbb81a96c8d69430b5d2df6bfd24`
- Windows x64と .NET 10 Desktop Runtime x64 が必要です。Markdown・HTMLには WebView2 Runtime も必要です。ランタイムはZIPに含まれていません。
- Windows 10実機では未確認です。旧版の設定を引き継ぐには、終了後に `UserData` を新しいEXEの隣へコピーしてください。
