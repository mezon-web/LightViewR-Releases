# LightViewR v0.3.9 配布検査

2026-10-26。旧版の配布物を維持したまま、現行アプリとソースの名称を LightViewR に統一した。

Windows の隔離デスクトップで発行済み ReadyToRun アセンブリの **770 項目** に成功した。配布 ZIP を展開して内部 SHA-256、Runtime と個人設定の非同梱、設定保存、PDF・Markdown・テキスト・表・HTML の起動、独立した 7 ウィンドウを確認した。起動測定は各形式 3 回。検査後に隔離デスクトップを解放した。

配布物は `LightViewR-v0.3.9.zip`（8,503,029 bytes、229 ファイル）。最上位フォルダは `LightViewR-v0.3.9`、起動フォルダには `LightViewR.exe` と `_support` のみを置く。ZIP に `UserData` と .NET / WebView2 Runtime は含まない。ZIP 内のファイル名と内容からユーザーフォルダ名・PC 固有パスを検査し、該当はなかった。

- ZIP SHA-256: `5b7a7f193546f66a220f496338ce3968b31f36b41953ab06aad2555fc7c238f0`
- EXE SHA-256: `157448003d08044f25e8157d35f218838bbc50e291e3f064fe574e60d36aabcb`

最初の全体検査では、透かし検出中のスクロール frame p95 が 20.5935 ms となり、20 ms の基準を超えた。原因は特定していない。同じ配布ビルドの全体再検査では 16.8066 ms で 770 項目と配布検査に成功した。この結果から長時間の性能安定性までは断定しない。

Windows 10 実機、実マウスでの手動操作、すべての混在方向・縦書き PDF は今回確認していない。過去のリリース ZIP と検証記録は当時の名称で保存する。

## 公開後の確認

公開リリースの `latest/download` から匿名で ZIP と SHA-256 ファイルを取得した。ダウンロードした ZIP はローカルの検証済み ZIP と SHA-256 が一致し、チェックサムファイルも同一だった。取得した ZIP を隔離デスクトップで展開・起動し、`UserData` の履歴と読書位置の保存、通常終了を確認した。隔離デスクトップは解放済み。
